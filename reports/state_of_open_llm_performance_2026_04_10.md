Models in the 7B–14B range now routinely exceed 70+ MMLU — a threshold that required 70B+ parameters in 2023. Microsoft Phi-4 (14B, MMLU: 84.8) and Qwen2.5-14B (14B, MMLU: 79.9) exemplify the data quality / architecture efficiency gains of 2024.

### 3. Code Generation Improvement

Mistral-Large-2407 achieves **HumanEval 92.1**, the highest among open-weight models, surpassing many proprietary systems. The gap between code-specialized and general models has narrowed significantly.

### 4. License Diversity Expands Access

Of the top 25 models: **10** use Apache 2.0, **4** use MIT, **3** use model-specific restrictive licenses (Llama 3, MRL, DeepSeek). True permissive open-source accounts for 56% of top performers — a significant shift from 2023.

### 5. Context Window is No Longer a Differentiator

128K context is now standard across Llama 3.1, Qwen2.5, Mistral-Large, and DeepSeek families. Competitive advantage has shifted to reasoning capability and benchmark efficiency.
